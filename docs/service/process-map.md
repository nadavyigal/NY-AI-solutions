# Process map: steps 0 to 7

Written 2026-11-12. One page. The [offer](offer.md) says what is sold; this
says what each step produces, what it costs the founder, and how we know it is
done. Founder hours are **guesses** until the [pilot](pilot-protocol.md)
replaces them with logged numbers.

| Step | What the client sees | Founder time (guess) | Exit test | Method lives in |
|---|---|---|---|---|
| **0 Discovery** | One call, then a short written recommendation or an honest "not now" | 2-3 h prep, 1 h call, 1 h write-up | Call logged in the fit-call log the same day. One named process and one recent real example | Toolkit 01 to 03 (compressed) |
| **0b Proposal and yes** | One proposal, one price, decision points | 1-2 h | The client says yes in writing. One value metric named. v1 went to the client before any v2 | Not written yet. This step was missing from the offer |
| **1 Safe start** | One AI tool set up in their own account, written data rules, three real tasks done | 1 h session, 1 h prep | Plan type and data setting verified and recorded in the account. Three tasks run there | Private hub, Journey guide. No template |
| **2 Taste and voice** | A style document and custom instructions that sound like the business | 1 h session, 2 h writing | The client judged two outputs and approved the text. It is live in the tool | Private hub, Journey guide. No template |
| **3 OS core** | One knowledge document, one or two assistants on it | 2-4 h | A change in the document shows up in an answer, tested in their account | Private hub, Journey guide. No template |
| **4 One live process** | One process working in their environment, a runbook, a before/after number | 8-15 h | Baseline recorded before the build. The client's own person ran a fresh case without help. Acceptance tests passed | Toolkit 01 to 06, private sprint guide |
| **5 System connection** | Only if step 4 needs it. A person approves every action | Unknown | Never-connect list enforced in the tool's settings. Vendor involved for any write | Toolkit 06 |
| **6 Independence** | About two weeks of real use, then an honest usage report | 1 h check, 1 h report | The adoption metric read from real use, reported even if it is zero | Toolkit 06 (embedding), private sprint guide |
| **7 Monthly improve** | A monthly review and the next process | 2-3 h a month | Opens only with step 6 evidence. Each month names one change and its owner | Not written yet |

## What this map shows

- **Two steps have no method yet:** 0b (proposal) and 7 (monthly).
- **Steps 1 to 3 have no template.** They run on the private Journey guide alone.
- **Every exit test is something that happens in the client's account or the
  log**, not a document handed over. A paste-ready file is not a delivered step.
- **The guesses for steps 1 to 6 add up to about 17 to 26 founder hours.** The
  live proposal assumes about 15 for the same span. Discovery and the proposal
  add another 5 to 7. The pilot will show which number is closer.
