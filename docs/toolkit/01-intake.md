# Step 1: Intake

Sent before the fit call. Ten minutes, async. Its job is to make the call about
one workflow instead of about AI in general.

---

## Client-facing form (Hebrew)

**על העסק**
1. מה העסק עושה, במשפט אחד?
2. כמה אנשים בצוות? מי עושה את העבודה החוזרת?

**מה כבר יש**
3. אילו מנויי AI העסק משלם עליהם היום? (ChatGPT / Gemini / Copilot / Claude / אחר)
4. מי בפועל משתמש בהם, וכמה?
5. אילו מערכות מרכזיות אתם עובדים איתן? (CRM, הנהלת חשבונות, מייל, וואטסאפ, אקסל)

**איפה כואב**
6. איזו עבודה חוזרת על עצמה כל שבוע ולוקחת הכי הרבה זמן?
7. מה קורה היום כשמישהו טועה בתהליך הזה?
8. אם היה אפשר להוריד דבר אחד מהצוות מחר בבוקר, מה הוא היה?

**מידע ורגולציה**
9. איזה סוג מידע של לקוחות עובר בתהליך הזה?
10. יש חובות רגולטוריות או מקצועיות שמגבילות איפה המידע הזה יכול לשבת?

## What I record (not sent to the client)

| Field | Value |
|---|---|
| Source of the introduction | |
| Segment | insurance / legal / finance / real estate / consulting / other |
| Headcount | |
| Paid AI subscriptions and **verified** tier | |
| Named candidate workflow | |
| Data sensitivity | low / client-identifying / regulated |
| Framing question that must be resolved before a report | |
| Qualified? | yes / no, and why |

**Verify the tier inside the account, do not accept the name of the plan.** What
a tier allows (knowledge files, connectors, retention settings) decides what can
be designed. Assuming it is a design risk. This came directly from the first
engagement.

**A required framing answer.** If the business could be described two ways and
the difference changes what the audit concludes, get the answer here. Carrying
it unresolved blocks the report.
