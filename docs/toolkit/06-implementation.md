# Step 6 — Implementation

Building the thing and getting it used. The sprint includes exactly one Quick
Win from this step; the rest is a separate scope and a separate agreement.

## Build rules

**Inside the tools they already pay for, first.** Configuration inside an
existing subscription beats a new platform, because it needs no procurement, no
migration and no new place for data to sit.

**One shared knowledge asset.** Voice, policy, terminology, and the privacy rule
live in one document attached to every assistant. A change is one edit. Four
separately tuned assistants drift within a month. This is the strongest single
lesson from the first engagement.

**The privacy rule is restated inside every artifact.** Not stored once in a
policy document. Artifacts get copied, pasted and edited; policies do not travel
with them.

**Connect nothing that does not need connecting.** The assistant handling the
most sensitive workflow should be a closed box: text in, drafts out, no
integrations. Connectors are earned per workflow, not granted by default.

**A human stays at the send step.** Drafts out, a person reviews, a person
sends. Anything that goes out unreviewed needs an explicit decision by the
client, recorded.

## Standing it up (the last mile)

This needs the client's own account and a scheduled session. **Book it at
kickoff.** In the first engagement everything was paste-ready weeks before
anything was live, purely because that hour was not scheduled.

Live session checklist:

1. Verify the tier and what it allows, in the account.
2. Audit connected apps and disconnect anything that exposes client data.
3. Stand up each assistant, attach the shared knowledge asset.
4. Walk the privacy path out loud, with the client, for each workflow.
5. Run one real instance together, with real inputs, aliased.
6. Confirm who owns it on Monday.

## Embedding

Training is part of the deliverable, not a follow-on. An unused workflow is a
failed workflow regardless of how well it works.

- Walk the person who does the job through their own workflow, in their words.
- Leave a one-page how-to inside the tool, not in an email.
- Check adoption at day 14: did they use it unprompted?

## Close-out

Re-take the step-3 baseline measures. Report them side by side, including the
ones that did not improve. A report that only shows wins destroys the trust the
"leave this alone" section bought.
